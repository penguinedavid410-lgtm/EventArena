# EventArena — Portfolio Project 2, Part 2

EventArena is a focused Streamlit chatbot for event discovery. It combines keyword rules with a TF-IDF and Logistic Regression intent classifier, plus a low-confidence fallback.

## Opening message and suggested questions

The chatbot greets the user with:

> Hello! Welcome to EventArena.
>
> Do you want to ask about one of these suggestions?

It offers five example questions:
1. What sports events are coming up?
2. Which concerts can I attend?
3. What festivals are happening?
4. What free or low-cost events are available?
5. How do I find an event's date, venue and ticket price?

A separate **Help** option explains the supported topics and how to use the chatbot. Each suggestion triggers a matching response. Users can also type their own question.

## Run locally

From the repository root, run:

    cd streamlit
    python -m venv .venv
    # Windows: .venv\Scripts\activate
    # macOS/Linux: source .venv/bin/activate
    pip install -r requirements.txt
    python train_model.py
    streamlit run app.py

The training script creates the classifier file and synthetic training dataset. The app also trains the model on first launch if the model file is absent.

## Deploy on Streamlit Community Cloud

1. Open Streamlit Community Cloud and choose **New app**.
2. Select this GitHub repository and the main branch.
3. Set **Main file path** to streamlit/app.py.
4. Deploy. Install requirements from streamlit/requirements.txt.

## Coursework evidence

Use streamlit/demo_conversations.md as a test guide. Run the app and capture genuine screenshots showing the welcome message, all five suggested questions, at least three classifier-handled paraphrases, a fallback, and two separate conversations. The app displays the handling route and confidence for each response.

## Limitations

All event listings are fictional sample records, not live or verified events. The intent dataset is synthetic. The confidence threshold is provisional and must not be described as production-calibrated. Report the evaluation generated by your own training run.
